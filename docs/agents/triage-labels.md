# Triage 标签

各工程技能使用五种标准 triage 角色。本文件将这些标准角色映射到本仓库 issue tracker 中实际使用的标签。

| mattpocock/skills 中的标签 | 本仓库中的标签        | 含义                         |
| -------------------------- | --------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`        | 需要维护者评估此 Issue       |
| `needs-info`               | `needs-info`          | 等待提交者补充信息           |
| `ready-for-agent`          | `ready-for-agent`     | 信息完整，可交给无人值守代理 |
| `ready-for-human`          | `ready-for-human`     | 需要人工实现                 |
| `wontfix`                  | `wontfix`             | 不会处理                     |

当技能提到某个角色时，例如“添加适合无人值守代理处理的标签”，应使用上表中对应的本仓库标签。

如果本仓库以后采用不同的标签命名，只需修改表格右侧的“本仓库中的标签”列。
